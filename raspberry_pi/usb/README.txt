ひもほどき：工作コントローラーのUSB接続

対象は CircuitPython が入った Raspberry Pi Pico / Pico W 系です。
元のWi-Fi版と同じ配線を使います。USBデータ通信対応ケーブルが必要です。
Raspberry Pi 4等のLinux機、純正Wiiリモコン、機種不明の基板にはこのコードをそのまま入れないでください。

1. 基板をPCにつなぎ、CIRCUITPYドライブが出ることを確認します。
   RPI-RP2は書き込み用の別モードです。機種・CircuitPythonの導入状況を作った人に確認してください。
2. 今のboot.pyとcode.pyをPCの別フォルダーにコピーして残します。
3. 同梱のboot.pyとcode.pyをCIRCUITPYの一番上に同じ名前でコピーします。
   既存のboot.pyで特別な設定がある場合は、作った人と統合してください。
4. USBを抜き差しします。boot.pyのUSB設定は電源を入れ直すまで反映されません。
5. PCのChromeまたはEdgeで https://31916.ch/himoparty/ を開きます。
6. 「コントローラーをつなぐ」→「Pico / Pico W（USBケーブル）」→「USBにつなぐ」。
7. データ用ポートを選びます。コンソール用とデータ用の2つが現れます。
   COM番号は環境で変わります。信号が届かなければ解除してもう一方を試します。
8. 手をはなして中央にもどした後、上下左右とAをひとつずつ試します。Bも確認できます。
   逆方向なら「左右を逆にする」「上下を逆にする」、中央のずれは「真ん中を合わせる」。
9. 「このコントローラーで遊ぶ」で開始。スティックで移動、A（または押し込み）で選択、
   選択後はスティックでひもの端を動かせます。Bではなす／操作メニュー。
   メニューからヒント・1手もどす・問題選択が使えます。

配線（元のraspberry_pi/code.pyと同じ）
横軸：GP26 / 縦軸：GP27
スティック押し込み：GP16 / A：GP0 / B：GP1
ボタンはPull.UPを使い、押すとGNDにつながります。
配線・軸の向きが異なる工作機器は、作った人と確認して調整してください。

うまくいかないとき
・ポートが開けない：Thonny、シリアルモニター、ほかのゲームタブを閉じます。
・信号待ちのまま：USB用の2ファイル、抜き差し、データ用ポートを確認します。
・途中で止まった：接続画面で再接続し、操作テスト後に再開します。
・普通のキーボードとして認識される工作機器は「キーボードとして動く機器」を使います。
・USB HIDゲームパッドは「USBゲームパッド」を使います。基板の書き換えは不要です。

元のraspberry_pi/code.pyとconnection_check/recv_test.pyはWi-Fi（UDP）用です。
ブラウザーはそのUDPを直接受けられないため、ここではUSB CDCデータ通信に切り替えます。
Wi-Fi設定、PC用サーバー、クラウドサーバー契約は不要です。入力はPC内で処理します。
元の動作に戻す場合は、保存したboot.pyとcode.pyを戻してUSBを抜き差ししてください。

初回はインターネット接続が必要です。ゲームの保存完了後は、この手順と2ファイルも
オフラインで開けます。USB接続許可は必要なときにブラウザーで行ってください。

通信仕様：115200 baud（USB CDC）、ASCII、改行区切り、約20Hz。
HIMO1,x,y,stick,A,B\n
x,y は -1〜1、ボタンは押したとき1、はなしたとき0。
元のUDP形式の0/1とは異なります。ブラウザー側がDTRを有効にして受信します。

検証範囲：通信の模擬テストとブラウザー操作を検証。実物のPicoでの動作は未確認です。
