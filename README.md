# ひもほどき

ひもの端を上下左右の空いた丸へ動かし、からまりをほどくパズルです。

**[ブラウザーで遊ぶ](https://31916.ch/himoparty/)**

## 遊び方

1. 色と数字のついたひもの端をえらびます。
2. 上下左右の空いた丸へ動かします。
3. 交差・接触しなくなったひもが消え、全部ほどけばクリアです。

20問、ヒント、１手もどす、やり直し、文字の拡大、BGMに対応しています。15秒以内で星3、30秒以内で星2、それ以降のクリアで星1。最速タイムと手数を保存します。

「操作方法」でマウス・タッチ／キーボード／コントローラーを選べます。工作機器は「コントローラーをつなぐ」から接続と操作を確認します。コントローラーのBでメニューを開き、スティックで移動、Aで決定できます。

交代するときは「次の人へ（リセット）」で星・タイム・途中の盤面を消し、問題1から始めます。文字サイズ・音楽設定・コントローラー接続は引き継ぎます。

Chrome / Edgeの「インストール」でPCアプリとして追加できます。初回の保存が終われば音楽も含めてオフラインで遊べます。音が出ない場合は「音楽：再生」を押してください。

## 開発・配信

Node.js 22以降で実行します。追加のnpmパッケージは不要です。

```sh
cd web
npm test
npm run build
npm start
```

`http://localhost:4173` で確認できます。配信するファイルは `web/dist/` です。このリポジトリではGitHub Pagesへ自動配信します。

- [ブラウザー版の操作と開発手順](web/README.md)
- [工作コントローラーのUSB接続](raspberry_pi/usb/README.md)
- [Processing版用コントローラーのWi-Fi接続](raspberry_pi/README.md)

`game/` は元のProcessing版、`connection_check/` はUDP接続テストです。BGMは `game/data/` の2曲を使用しています。
