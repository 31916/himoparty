# ひもほどき PWA

PCブラウザー向けの１人用パズル。表示名「ひもほどき」は初版の仮名です。

## 遊び方

「操作方法」でマウス・タッチ／キーボード／コントローラーを選びます。盤面下の案内は操作方法と、選択前・ひもの選択中・クリア後の状態に合わせて切り替わります。盤面のクリック／タップや通常のキーボード操作でも案内を自動で切り替えます。コントローラーを選ぶと接続画面が開き、操作テスト後に開始します。

1. 色と数字のついた、ひもの端をクリックします。
2. 上下左右のとなりの空いた丸をクリックして動かします。
3. 他のひもと交差・接触しなくなったひもは消えます。全部消せばクリアです。

ドラッグは不要です。キーボードでは、Tabで盤面に入り、矢印で丸を移動、EnterまたはSpaceで選択できます。選択中は矢印でひもの端を動かし、Escで選択を解除します。

20問、ヒント、１手戻す、やり直し、文字の拡大、星と最速記録、途中の盤面保存を備えます。初期盤面には検証済みの解答手順があります。違う手を選んだ場合はWeb Workerで解答を探索します。探索には件数・時間の上限があり、ヒントを見つけられない場合は１手戻す操作を案内します。「解けない」という判定は行いません。

### 音楽と星評価（0.4.0）

元の `game/HomeScreen.pde` と同じ評価を復元しました。**15秒以内：星3、30秒以内：星2、それ以降のクリア：星1**。制限超過によるゲームオーバーはありません。調査した元の両リポジトリに手数の評価条件はなく、手数は表示と最速タイムに付随する記録として保存します。

問題の表示時から計測し、ヒント・Undo・メニュー・接続設定・タブを閉じた時間も含めます。クリアで停止し、「はじめから」で0秒に戻ります。再読込でタイマーはリセットされません。Undoでも時間は巻き戻りません。既存の最高記録は遅い再クリアで下がりません。更新前のクリア済み問題は星1として引き継ぎ、未知の時間は「計測なし」と表示します。更新前の途中盤面からの再開も時間を推定せず、再挑戦で計測します。「次の人へ」は星・タイムも消去します。

元のMP3 2曲をビルド時に `game/data/` からコピーし、問題一覧では `bgm_home.mp3`、プレイ中は `bgm_stage.mp3` をループ再生します。「音楽」で入／切を切り替え、設定は次の人にも引き継ぎます。タブが非表示なら音楽を止めます。自動再生が許可されないブラウザーでは最初のクリック・キー操作、または「音楽：再生」で再生します（[ブラウザーの自動再生方針](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)）。コントローラーのBメニューからも音楽と星の条件を操作できます。

2曲は他のファイルと一緒に事前キャッシュします。Service Workerはオフラインの音声Rangeリクエストに206で応答します（[音声キャッシュの注意点](https://developer.chrome.com/docs/workbox/serving-cached-audio-and-video)）。初回の保存容量は従来より約6.4 MB増えます。

### 人が交代するとき（0.2.1）

「次の人へ（リセット）」→「記録を消して交代する」で、クリア記録・問題番号・途中の盤面・Undo履歴・ヒントをリセットし、問題1から始めます。確認画面は「交代しない」を初期選択します。キャンセルした場合は進み具合を維持します。

文字サイズ、コントローラーの接続、方向反転、接続中の中央補正は引き継ぎます。交代時にボタン・スティックを一度離すまで、操作は再開しません。消した進み具合はUndoで戻せません。「はじめから」は現在の問題だけをやり直し、クリア記録を残す操作です。

## 工作コントローラー（0.2.0）

ゲームを開いた画面の「コントローラーをつなぐ」から、次の方式を選びます。

- **Pico / Pico W（USBケーブル）**：CircuitPythonのUSBデータ用ポートをWeb Serialで受信します。画面内の「はじめての準備」から2ファイルと配線手順を保存できます。元のWi-Fi版コードのままUSBを挿すだけでは動きません。
- **USBゲームパッド**：Gamepad APIで認識する機器。標準マッピングは左スティック・十字キー・A/Bに対応。標準以外の機器は軸1/2・ボタン1/2を仮に割り当てるため、テストで確認します。
- **キーボードとして動く機器**：矢印、A/BまたはEnter/Escを送る機器。PCの普通のキーボードとは区別できません。

接続画面ではパズルを動かさず、上下左右とAを確認した後に開始します。Bは任意で確認できます。スティックで丸を選び、Aで端を選択し、スティックで隣へ動かします。Bで選択を解除、未選択なら操作メニューからヒント・Undo・問題選択ができます。

操作メニューでは下・右で次の項目、上・左で前の項目へ移り、Aで決定、Bで閉じます。「はじめから」と「次の人へ（リセット）」も選べます。使用できない項目は飛ばし、選択中の項目を枠で示します。ひもを選んでいるときは、Bで一度はなしてから、もう一度Bでメニューを開きます。コントローラーで遊んでいる間は、盤面下にもこの案内を表示します。

ポート選択はユーザーが押したときだけ行います。接続切断や信号途絶時は操作を止め、再テストで再開します。接続種別と方向反転は `himohodoki-controller-v1` に保存し、中央の補正値と接続許可は自動復元しません。入力データのサーバー送信はありません。

Pico用コードと詳しい仕様は [raspberry_pi/usb](../raspberry_pi/usb/README.md)。実機の接続・操作感は未検証です。

## 開発

Node.js 22以上。推奨・CIはNode.js 24。外部依存、CDN、解析ツール、外部フォントはありません。

PCの横長画面は高さに合わせて盤面を伸縮します。文字拡大を含め1024×600以上で主な操作が収まることを確認しています。狭い画面や強いブラウザー拡大では縦に並べてスクロールできる配置に切り替え、ボタンを切り落としません。旧版の紹介文・励まし文・常時の保存／オフライン表示・盤面下の固定文言は削除しています。

```sh
npm test
npm run build
npm start
```

`http://localhost:4173` で確認します。変更後は再ビルドが必要です。Service Worker更新後に出る「更新する」を押すと、保存した盤面を保ったまま新しい版に切り替わります。

- `npm run generate:levels`：固定シードで問題と解答を再生成。問題番号と保存データは対応するため、公開後の問題変更には保存データの移行が必要です。
- `node tools/build-icons.mjs`：コードで定義したオリジナルのロゴからPNGアイコンを生成。
- `npm test`：ルール・全20問の解答・保存復元・PWAの配信ファイル・USB受信とコントローラー入力を検証。
- `npm run build`：必要な19ファイルを `dist/` に出力。Pico用の3ファイルは `../raspberry_pi/usb/` からコピー。ファイルのハッシュによりキャッシュの版を自動更新。
- リポジトリの一番上で `python -m unittest discover -s raspberry_pi/usb -p 'test_*.py'`：ファームウェアの模擬テスト。追加ライブラリーは不要。

## 公開

`dist/` の内容を、そのままHTTPSの静的ホスティングに配置してください。ルートURLでも `/himohodoki/` のようなサブディレクトリでも使えます。マニフェスト、アイコン、スクリプト、Service Workerを含む構成を保ってください。`dist/` 以外のソースやProcessing素材は配信不要です。

- `sw.js` は `Cache-Control: no-cache` を推奨。
- JavaScriptはJavaScriptのMIMEタイプ、マニフェストは `application/manifest+json` で配信。
- `file://` からの直接起動ではPWAは機能しません。開発はlocalhost、本番はHTTPSを使用します。
- Chrome / Edgeでのデスクトップインストールを想定。ブラウザーの対応状況や既存のインストール状態に応じ、画面のインストールボタンは標準のインストール画面または手順説明を開きます。
- 常時のオフライン状態表示はありません。インストール手順のダイアログでは準備状態を確認できます。初回アクセスには通信が必要です。
- 新版はすべての配信ファイルをキャッシュできた場合だけ利用可能になります。更新ボタンを押すまで、開いている画面には現在の版を使います。

公開URLとインストール確認は配信後に検証してください。PWAの一般的な要件は [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) を参照しています。

## 記録とプライバシー

記録は `localStorage` の `himohodoki-v1` に保存します。保存する情報は、問題番号、操作履歴（上限1000手）、クリアした問題、文字サイズ設定です。アカウント、広告、アクセス解析、記録送信はありません。ホスティング事業者の通常のアクセスログは配信先の設定によります。

記録は端末・ブラウザーごとで、同期しません。ブラウザーのサイトデータを削除すると記録は消えます。保存できない場合のみ画面上で案内し、ゲーム自体は継続できます。古い・壊れた保存内容や不正な手は読み込み時に検証して初期盤面に戻します。
