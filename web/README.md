# ひもほどき PWA

PCブラウザー向けの１人用パズル。表示名「ひもほどき」は初版の仮名です。

## 遊び方

1. 色と数字のついた、ひもの端をクリックします。
2. 上下左右のとなりの空いた丸をクリックして動かします。
3. 他のひもと交差・接触しなくなったひもは消えます。全部消せばクリアです。

ドラッグは不要です。キーボードでは、Tabで盤面に入り、矢印で丸を移動、EnterまたはSpaceで選択できます。選択中は矢印でひもの端を動かし、Escで選択を解除します。

20問、ヒント、１手戻す、やり直し、文字の拡大、クリア記録、途中の盤面保存を備えます。速さによる評価や制限時間はありません。初期盤面には検証済みの解答手順があります。違う手を選んだ場合はWeb Workerで解答を探索します。探索には件数・時間の上限があり、ヒントを見つけられない場合は１手戻す操作を案内します。「解けない」という判定は行いません。

## 開発

Node.js 22以上。推奨・CIはNode.js 24。外部依存、CDN、解析ツール、外部フォントはありません。

```sh
npm test
npm run build
npm start
```

`http://localhost:4173` で確認します。変更後は再ビルドが必要です。Service Worker更新後に出る「更新する」を押すと、保存した盤面を保ったまま新しい版に切り替わります。

- `npm run generate:levels`：固定シードで問題と解答を再生成。問題番号と保存データは対応するため、公開後の問題変更には保存データの移行が必要です。
- `node tools/build-icons.mjs`：コードで定義したオリジナルのロゴからPNGアイコンを生成。
- `npm test`：ルール・全20問の解答・保存復元・PWAの配信ファイルを検証。
- `npm run build`：必要な13ファイルだけを `dist/` に出力。ファイルのハッシュによりキャッシュの版を自動更新。

## 公開

`dist/` の内容を、そのままHTTPSの静的ホスティングに配置してください。ルートURLでも `/himohodoki/` のようなサブディレクトリでも使えます。マニフェスト、アイコン、スクリプト、Service Workerを含む構成を保ってください。`dist/` 以外のソースやProcessing素材は配信不要です。

- `sw.js` は `Cache-Control: no-cache` を推奨。
- JavaScriptはJavaScriptのMIMEタイプ、マニフェストは `application/manifest+json` で配信。
- `file://` からの直接起動ではPWAは機能しません。開発はlocalhost、本番はHTTPSを使用します。
- Chrome / Edgeでのデスクトップインストールを想定。ブラウザーの対応状況や既存のインストール状態に応じ、画面のインストールボタンは標準のインストール画面または手順説明を開きます。
- 画面下の「オフラインでも遊べます」はService Workerの初回キャッシュ完了後に表示します。初回アクセスには通信が必要です。
- 新版はすべての配信ファイルをキャッシュできた場合だけ利用可能になります。更新ボタンを押すまで、開いている画面には現在の版を使います。

公開URLとインストール確認は配信後に検証してください。PWAの一般的な要件は [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) を参照しています。

## 記録とプライバシー

記録は `localStorage` の `himohodoki-v1` に保存します。保存する情報は、問題番号、操作履歴（上限1000手）、クリアした問題、文字サイズ設定です。アカウント、広告、アクセス解析、記録送信はありません。ホスティング事業者の通常のアクセスログは配信先の設定によります。

記録は端末・ブラウザーごとで、同期しません。ブラウザーのサイトデータを削除すると記録は消えます。保存できない場合は画面下で案内し、ゲーム自体は継続できます。古い・壊れた保存内容や不正な手は読み込み時に検証して初期盤面に戻します。

## 初版の範囲

１人用、20問、無音です。専用コントローラー、複数人同時操作、アカウント同期は含みません。元のProcessing版の機能は元のフォルダーに残しています。小学生・高齢者本人による使い勝手・難易度の検証と、各ブラウザーでの実インストール検証は今後の課題です。
