# ひもほどき PWA

PCブラウザーで遊べる、１人用・20問のパズルです。

## 操作

「操作方法」で入力機器を選びます。盤面下の案内は、選んだ機器とひもの選択状態に合わせて変わります。

- マウス・タッチ：ひもの端をえらび、上下左右の空いた丸をクリック／タップ。
- キーボード：矢印で移動、Enter / Spaceで選択、Escではなす。Tabで操作ボタンへ移動。
- コントローラー：スティックで移動、Aで選択、Bではなす。もう一度Bでメニュー、スティックで項目を移動、Aで決定。

ヒント・１手もどす・はじめからを使えます。「次の人へ」は確認後にクリア記録と途中の盤面を消し、問題1へ戻します。文字サイズ、音楽、コントローラー設定は引き継ぎます。

## 星と音楽

15秒以内で★★★、30秒以内で★★☆、それ以降のクリアで★☆☆。問題の表示から計測し、クリアで停止します。ヒント・メニュー・Undo・閉じている時間も含み、再読込ではリセットされません。「はじめから」で0秒に戻ります。手数は最速タイムと一緒に記録します。

問題一覧に最速記録の星を表示します。時間を計測していなかった古いクリア記録は星1・「計測なし」で引き継ぎます。

問題一覧とプレイ中でBGMが切り替わります。「音楽」で入／切を切り替えます。最初に音が出ない場合は画面をクリックするか「音楽：再生」を押してください。

## 接続・インストール

工作機器のUSB接続は [コントローラーの手順](../raspberry_pi/usb/README.md) を参照してください。Pico / Pico WのUSBシリアル、USBゲームパッド、キーボードとして動く機器に対応します。純正Wiiリモコンの直接接続には対応していません。

Chrome / Edgeで画面の「インストール」を使うと、PCアプリとして追加できます。初回の読み込みと保存が終われば、盤面・ヒント・BGM・接続手順をオフラインでも利用できます。更新がある場合は「更新する」で切り替えます。

## 開発

Node.js 22以降。追加パッケージは不要です。

```sh
npm test
npm run build
npm start
```

`http://localhost:4173` を開きます。`npm run generate:levels` で問題を生成できます。USBコードのテストはリポジトリ直下で `python -m unittest discover -s raspberry_pi/usb -p 'test_*.py'` を実行します。

`dist/` をHTTPSの静的ホスティングへ配置します。ルートURLでもサブディレクトリでも動きます。`file://` ではPWAを利用できません。Service Workerは配信物全体が保存できた版へ更新します。

## 記録

進み具合・星・タイム・操作設定は、この端末のブラウザー内に保存します。アカウント登録、広告、アクセス解析、ゲーム記録の送信はありません。端末間の同期は行わず、ブラウザーのデータを消すと記録も消えます。
